# Przyroda

Rodzinna aplikacja do nauki przyrody (klasa 4): lekcje z podręcznika z nagraniami do słuchania z książką,
ćwiczeniami i ściągą, poprawka z wyjaśnieniem po każdym błędzie i wynik wysyłany rodzicowi.

https://przyroda.ogarnijmaterial.pl (logowanie na https://ogarnijmaterial.pl)
